# Portfolio

A personal portfolio website showcasing selected projects, creative work, and ways to connect.

## Run locally

This repository contains a static `index.html` entry point. Preview it with Python's built-in web server:

```bash
python -m http.server 8000
```

Then open http://localhost:8000 in your browser.

## Project structure

- `index.html` — portfolio page and its client-side assets and styles.

## Development

1. Clone the repository.
2. Open the project directory.
3. Start the local server using the command above.
4. Make changes and refresh the browser to preview them.

## Contributions

For substantial changes, use a focused branch and describe the user-facing impact in the pull request.
