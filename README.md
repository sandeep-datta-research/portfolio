# Sandeep Datta — Personal Portfolio

A personal portfolio built from the open-source **ECHO** editorial portfolio by [Jishnu Mondal](https://github.com/Jishnu09-siuu/ECHO-WEBSITE), adapted for Sandeep Datta with updated identity, project descriptions, and social links.

## About
Developer, AI builder, and creative technologist exploring software, AI, Linux, cybersecurity fundamentals, networking, research, video editing, and writing.

## Featured work
- **Luna AI** — an AI assistant project under development by DeimosAI.
- **DeimosAI** — a creative technology umbrella brand and project ecosystem.
- **Anime video editing** — AMVs and short-form visual storytelling under the seiua amv identity.
- **Clouded by You** — an original romance, mystery, and supernatural-weather webnovel by ifsato.

## Built with
HTML, CSS, vanilla JavaScript modules, Tailwind CSS CDN, and OGL/WebGL for interactive visual effects.

## Run locally
Python 3 is enough:
```bash
python3 -m http.server 8080
```
Then open `http://localhost:8080`.
